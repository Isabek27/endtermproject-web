О проекте

MatchIQ Pro — демонстрационный сайт футбольной статистики, созданный для учебного проекта по Web Technologies.

Здесь можно изучать матчи, сравнивать игроков, смотреть таблицы и пример прогнозов.

JavaScript проверяет имя, email, тему, текст сообщения и согласие. Если есть ошибки, отправка блокируется.
